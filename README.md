## About this entry

**The Day in One Page** is a one-page broadsheet summing up the world's news of **Sunday 22 November 2026** in a single 1024×1024 image. The front page leads with the day's three biggest stories — the COP31 climate talks in Antalya entering a second day of overtime, Mexico's capture of cartel boss 'El Chapo Isidro', and the Russian drone strike that destroyed a Kyiv apartment block — followed by 24 more stories of the day in ruled columns: World, Politics, Science/Tech/Economy, Disasters & Justice, Sport and Culture.

The page is hand-written HTML with inline CSS (`page.html`), rendered once to `entry.png`. The hand-in program (`main.ts`) copies `entry.png` from beside itself into the output directory named by `MAKEFUN_OUTPUT_DIR` (default `/output`). It is deterministic and runs with no network.
